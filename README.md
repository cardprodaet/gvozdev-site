# Карточка продает — сайт Владислава Гвоздева

Статический сайт эксперта по продажам на Wildberries и Ozon.
Публикуется через GitHub Pages: https://cardprodaet.github.io/gvozdev-site/

## Структура

```
index.html            главная
about.html            обо мне
services.html         услуги
cases.html            кейсы
contacts.html         контакты
blog.html             список статей
blog-*.html           статьи блога (16 шт.)
thank-you.html        страница после отправки заявки
404.html              страница ошибки

assets/css/base.css   общие стили: переменные, сброс, шапка, подвал,
                      мобильное меню, кнопки, плавающие контакты
assets/js/main.js     общее поведение: мобильное меню, FAQ, липкая шапка,
                      появление блоков при прокрутке

favicon.svg, robots.txt, sitemap.xml
expert.jpg + expert.webp   фото: WebP основной, JPEG запасной
```

## Как устроены стили

`base.css` подключается на каждой странице **до** её собственного блока
`<style>`. Всё, что объявлено в странице, переопределяет базовое — так
постраничные отличия остаются на своих местах, а общий слой не дублируется.

Цвета и радиусы заданы CSS-переменными в `:root` (`--bg`, `--accent`,
`--text` и т. д.). Меняйте их в `base.css`, а не по месту.

## Как устроены скрипты

`main.js` подключается с `defer` перед `</body>` на всех страницах, где есть
шапка. Он объявляет `toggleMenu()` и `toggleFaq()` (их вызывает разметка) и
самостоятельно инициализирует липкую шапку и появление блоков.

Блоки с классом `.reveal` проявляются при прокрутке. Вложенные полосы с
атрибутом `data-w` (графики кейсов, шкалы навыков) заполняются на ширину
`data-w` процентов.

Короткий скрипт в `<head>` ставит классу `<html>` признак `js`. Без него
CSS показывает содержимое сразу — если скрипты не загрузятся, страница
останется читаемой.

## Локальный просмотр

Относительные пути к `assets/` требуют HTTP, открытие файла напрямую их не
разрешит. Поднимите любой статический сервер в корне проекта:

```bash
python3 -m http.server 8123
```

Затем откройте http://localhost:8123

## Форма заявок

Форма на `contacts.html` работает без серверной части. При отправке она проверяет
поля, собирает текст заявки и открывает Telegram с уже подставленным сообщением —
посетителю остаётся нажать «отправить». Рядом появляется кнопка WhatsApp на случай,
если вкладка не открылась или удобнее другой мессенджер.

Никаких ключей и токенов на страницах нет: исходный код сайта виден любому
посетителю, поэтому хранить в нём секреты нельзя. Заготовка серверного варианта
(заявка уходит в бота сама) лежит в [`worker/`](worker/README.md) — на случай,
если понадобится.

## Аналитика

Подключена Яндекс.Метрика (счётчик `109215727`). Цель `form_submit` засчитывается
в момент отправки формы на `contacts.html`, а также на `thank-you.html`.
