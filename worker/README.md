# Приём заявок через Cloudflare Worker

> **Сейчас этот вариант не используется.** Форма на сайте работает без сервера:
> собирает заявку и открывает мессенджер с готовым текстом. Токенов на сайте нет,
> и этот обработчик не нужен.
>
> Папка оставлена на будущее. Если заявок станет много и лишний шаг с переходом
> в мессенджер начнёт мешать — здесь всё готово к развёртыванию, останется
> пройти шаги ниже.

Вариант с обработчиком нужен, когда заявка должна уходить в бота автоматически,
без участия посетителя. Токен бота при этом хранится в настройках Cloudflare
и в исходный код страницы не попадает.

```
Форма на сайте  →  Cloudflare Worker (здесь токен)  →  Telegram
```

## Порядок настройки

### 1. Новый токен бота

Старый токен был виден в коде опубликованного сайта, поэтому считаем его
скомпрометированным. В Telegram у [@BotFather](https://t.me/BotFather):

1. `/mybots` → выберите бота → **API Token** → **Revoke current token**
2. BotFather выдаст новый токен — скопируйте его

Отзывайте **после** того, как выполните шаги 2–4: до этого момента заявки
продолжают приходить по-старому.

### 2. Создать Worker

1. Зайдите на [dash.cloudflare.com](https://dash.cloudflare.com) (регистрация бесплатна)
2. В меню слева: **Workers & Pages** → **Create** → **Create Worker**
3. Задайте имя, например `gvozdev-lead-form`, нажмите **Deploy**
4. Нажмите **Edit code**, удалите содержимое и вставьте код из
   [`lead-form-worker.js`](lead-form-worker.js)
5. **Deploy**

### 3. Прописать переменные

В настройках воркера: **Settings** → **Variables and Secrets** → **Add**.

| Имя | Значение | Тип |
|---|---|---|
| `TG_TOKEN` | новый токен от BotFather | **Secret** (зашифрованная) |
| `TG_CHAT_ID` | `911552952` | Text |
| `ALLOWED_ORIGIN` | `https://cardprodaet.github.io` | Text |

`TG_TOKEN` обязательно тип **Secret** — тогда он не показывается даже в панели.

После добавления переменных нажмите **Deploy** ещё раз.

### 4. Подставить адрес в форму

Скопируйте адрес воркера — он вида
`https://gvozdev-lead-form.ВАШ-ЛОГИН.workers.dev`

Откройте `contacts.html`, найдите строку:

```js
const FORM_ENDPOINT = 'ВСТАВЬТЕ_АДРЕС_ВОРКЕРА';
```

и подставьте адрес.

### 5. Проверить

Отправьте тестовую заявку с сайта. Сообщение должно прийти в Telegram.
Если не пришло — смотрите **Logs** в панели воркера, там видно причину.

### 6. Отозвать старый токен

Теперь возвращайтесь к шагу 1 и отзывайте старый токен. Новый уже работает
через воркер, так что приём заявок не прервётся.

## Что умеет обработчик

- **Принимает только с вашего сайта** — запросы с чужих адресов отклоняются
  (`ALLOWED_ORIGIN`)
- **Ловушка для ботов** — в форме есть скрытое поле `company`; люди его не видят,
  автоматика заполняет. Такие заявки молча отбрасываются
- **Ограничение частоты** — не больше 5 заявок в минуту с одного адреса
- **Обрезает длинные значения** — защита от мусорных полей на мегабайт
- **Экранирует разметку** — спецсимволы в тексте не ломают сообщение в Telegram

## Если обработчик недоступен

Форма это переживёт: посетитель увидит сообщение с кнопкой «Написать в Telegram»,
в которой текст заявки уже подставлен. Заявка не потеряется.

## Стоимость

Бесплатный тариф Cloudflare — 100 000 запросов в сутки. Для сайта с заявками
этого хватает с большим запасом.
